# مصروفي | My Expenses Smart Budget Management

مشروع Android لتطبيق مصروفي.

## أحدث إصدار

- الإصدار: **2.0** (versionCode **4**)
- اسم التطبيق: **مصروفي**
- [تنزيل APK الإصدار 2.0](release/Masrofi-v2.0-debug.apk)
- [تنزيل ملفات مصدر الإصدار 2.0](release/Masrofi-v2.0-source.zip)

تظل ملفات الإصدارات السابقة محفوظة في مجلد `release`.

## البناء والاختبارات

يتطلب المشروع Android SDK 36 وJDK 21. شغّل:

```bash
./gradlew assembleDebug testDebugUnitTest
```

لا ترفع مفاتيح API أو ملفات التوقيع الخاصة أو ملف `debug.keystore` إلى المستودع.
